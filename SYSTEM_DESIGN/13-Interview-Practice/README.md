## Practice Rules

- One hand-drawn artifact per session; no slides while speaking.
- State assumptions aloud before drawing components.
- Spend the final four minutes on failure and trade-offs.
- Record every number with a unit.
- After each mock, list one missing invariant, one unquantified bottleneck, and one unhandled failure.
- Revisit failed questions after 1, 3, 7, and 14 days.

## Readiness Gates

- [ ] Complete two designs in 45 minutes without exceeding scope.
- [ ] Explain every chosen component through a requirement.
- [ ] Name a rejected alternative and its accepted cost.
- [ ] Handle one dependency failure without losing the core invariant.
- [ ] Deliver a capacity estimate with sanity checks.
- [ ] Answer a follow-up that attacks the chosen trade-off.
